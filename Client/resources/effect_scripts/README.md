# 효과 문자 아트

## 회복

`heal_image.txt`는 왼쪽 위·오른쪽 중앙·하단 중앙에 다이아몬드 세 개를 배치한 회복용 문자 아트입니다.

- 크기: 24×24픽셀, 콘솔에서는 48글자×24줄.
- 픽셀: `██`. 공백은 투명하게 처리합니다.
- 테두리: 초록 `#28AE50`, 내부: 연두 `#B8F26D`.
- 인코딩: UTF-8, ANSI 24비트 전경색. 기존 타입 이미지와 같은 형식입니다.
- 빌드·배포 결과물에 함께 복사됩니다.
- Held Item Activate가 끝나고 Heal HP Restore가 재생되는 동안 회복 대상 포켓몬 위에 덧그린 뒤 지웁니다.

## 몬스터볼

`pokeball_image.txt`는 빨간 상단, 흰 하단, 검은 중앙 띠와 원형 버튼이 있는 몬스터볼 문자 아트입니다.

- 크기: 24×24픽셀, 콘솔에서는 48글자×24줄.
- 한 픽셀: 같은 색의 `██`; 빈 픽셀: 공백 두 글자.
- 인코딩: UTF-8 (BOM 없음), ANSI 24비트 전경색. 각 줄 끝에서 색상을 초기화합니다.
- 배경색을 지정하지 않으며, 빌드·배포 결과물에 함께 복사됩니다.

## 승리·패배 로고

포켓몬 로고처럼 굵은 글자와 테두리로 만든 결과 화면용 문자 아트입니다.

- `victory_image.txt`: `Victory!`, 70×28픽셀(140글자×28줄), 검정 `#000000` 테두리와 노란색 `#FFCB05` 내부.
- `loss_image.txt`: `Loss...`, 58×23픽셀(116글자×23줄), 검정 `#000000` 테두리와 연한 빨간색 `#FF9999` 내부.
- 승리·패배 결과 화면에 해당 아트를 표시하고, 콘솔이 작으면 비율을 유지해 축소합니다. 재도전·나가기 메뉴는 그림 아래에 표시합니다.
- 한 픽셀은 `██` 두 글자이며, 빈 픽셀은 공백 두 글자입니다.
- UTF-8(BOM 없음), ANSI 24비트 전경색 형식이며 각 줄 끝에서 색상을 초기화합니다.
- 배경색을 지정하지 않으며, 빌드·배포 결과물에 함께 복사됩니다.
