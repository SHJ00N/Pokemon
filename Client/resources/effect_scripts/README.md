# 회복 효과 문자 아트

`heal_image.txt`는 왼쪽 위·오른쪽 중앙·하단 중앙에 다이아몬드 세 개를 배치한 회복용 문자 아트입니다.

- 크기: 24×24픽셀, 콘솔에서는 48글자×24줄.
- 픽셀: `██`. 공백은 투명하게 처리합니다.
- 테두리: 초록 `#28AE50`, 내부: 연두 `#B8F26D`.
- 인코딩: UTF-8, ANSI 24비트 전경색. 기존 타입 이미지와 같은 형식입니다.
- 빌드·배포 결과물에 함께 복사됩니다.
- Held Item Activate가 끝나고 Heal HP Restore가 재생되는 동안 회복 대상 포켓몬 위에 덧그린 뒤 지웁니다.
